🌺 La Fleur des Fichiers de Killtime Tactics

Chaque pétale est un fichier du code maison, qui éclot à la date de sa création git (354 fichiers, 8 Septembre 2026 au 12 Octobre 2026). La couleur indique son module, la chronologie sa naissance.

🌸 Pétales métier : 13 domaines (Personnage, Combat, Tactique, Récit, Ateliers, Arène, Interface, Multijoueur, Audio, Caméra, Tests, Données, Visuels) — regroupés par usage, pas par dossier.
🔗 4 couches de liaisons commutables (interrupteurs sous les vues) : Synapses violettes = co-évolution (épaisseur = commits communs), Héritage cyan fléché = classe fille → parente, Partials pointillés = satellite → fichier principal, Tests verts = test → testé.
🔥 Halo de churn : l'auréole orange pulse selon l'instabilité (nombre de commits). Anneau rouge tournant = ⚠️ hotspot (gros et instable).
🧪 Lunes de tests : les satellites verts orbitent les fichiers couverts par des tests — cliquez un fichier pour sauter vers ses tests.
📏 Taille vivante : le rayon de chaque nœud = ses lignes réelles à la date affichée — les fichiers gonflent et maigrissent pendant la lecture.
🎵 Synthèse Sonore : Harmonie céleste pentatonique générée en temps réel à chaque floraison.
🕹️ Navigation : Glissez pour déplacer la vue, molette pour zoomer, cliquez sur un nœud pour voir l'historique complet du fichier.
⌨️ Raccourcis : Espace Play/Pause, ← / → Reculer/Avancer.
