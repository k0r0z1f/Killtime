## 1. Le projet en une phrase

**Killtime**, c'est un univers tactique complet : un système de jeu de rôle original publié en 12 livres web gratuits, un jeu vidéo tactique Unity en cours de développement, et une saga narrative associée.

## 3. Mandats proposés (au choix, 1 seul par stagiaire/équipe)

### Mandat A — Tranche démo tech jouable Unity (recommandé)
- Objectif : faire avancer une tranche jouable 5-10 min (escouade 2v2, couvert, IA ennemie simple, conditions de victoire). **Le chantier dépasse un seul stage : l'évaluation porte sur le travail réellement accompli (commits, revue hebdo), pas sur l'état de livraison de la démo.**
- Tâches : gameplay C#, UI combat, debug, builds Windows.
- Livrable : build stable + vidéo 60-90s **selon avancement**.

### Mandat B — Outils web du Codex
- Objectif : fiche de personnage interactive + lanceur de dés en ligne.
- Tâches : HTML/CSS/JS, tests navigateurs, mise en ligne.
- Livrable : pages déployées sur le site public.

### Mandat C — Contenu (selon profil)
- Objectif : bestiaire illustré / scénario d'initiation pour playtests.
- Livrable : PDF mis en page, crédité au nom de l'auteur.

## 4. Encadrement proposé

- Supervision directe par le porteur (disponible [X]h/semaine, revue de code hebdo).
- Tâches découpées type kanban, critères d'acceptation écrits.
- Matériel fourni : repo, documentation, builds, assets existants.
- Stage : convention tripartite école-stagiaire-milieu, objectifs de stage écrits avant démarrage.
- Suivi : revue hebdo + journaux via commits Git ; **évaluations mi-stage et finale** sur les formulaires du collège ; disponibilité pour la **visite ou l'appel du superviseur enseignant**.
- Intégration : accès repo, documentation, outillage dès le jour 1 ; tâches progressives alignées sur les compétences du programme.
- Rapport : temps réservé en fin de stage pour la rédaction du rapport de stage et la préparation de la présentation.
- Projet d'équipe : encadrement pédagogique du collège conservé, le porteur agit comme « client + référent technique ».
